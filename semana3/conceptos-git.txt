Repositorio:
Un repositorio es un espacio donde se almacenan los archivos y cambios de un proyecto. Permite organizar el trabajo y mantener un historial de modificaciones realizadas por los desarrolladores.

Commit:
Un commit es un registro de cambios realizados en un proyecto. Sirve para guardar versiones del trabajo y poder identificar qué modificaciones se hicieron en cada momento.

Push:
El comando push se utiliza para enviar los cambios del repositorio local hacia un repositorio remoto como GitHub. Esto permite compartir y respaldar el proyecto en línea.
